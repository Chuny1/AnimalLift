# Model and auxiliary assets

Auxiliary assets are included in this ZIP under `assets/`. The checkpoint is distributed separately. Download availability is listed in the [README](../README.md#downloads).

Place the checkpoint at `ckpt/latest.pt`. For a source-only checkout, extract the auxiliary bundle into `assets/`. If files are stored elsewhere, set their paths in `config.local.json` or pass a configuration file with `--config`.

## Asset layout

| Path | Purpose | Required by |
| --- | --- | --- |
| `ckpt/latest.pt` | AnimalLift SD-VAE multitask checkpoint | Inference; resuming training |
| `assets/reference.obj` | Mesh topology and UV coordinates | Inference and training validation |
| `assets/UV_Occupancy.png` | UV occupancy mask for texture losses | Training |
| `assets/hair_map_meta_uvanchor.npz` | Hair groups and surface anchors | Blender |
| `assets/underhair_mask.png` | Undercoat distribution mask | Blender |
| `assets/Normal.png` | Surface normal map | Blender with texture loading enabled |
| `assets/Roughness.png` | Surface roughness map | Blender with texture loading enabled |
| `assets/uv_source.obj` | UV fallback mesh | Blender, when the imported mesh has no UVs |
| `assets/kloofendal_28d_misty_2k.hdr` | Environment lighting | Blender with `--use_hdri` |
| `assets/base_texture.png` | Base UV texture | Optional texture generation |

The reference OBJ must match the checkpoint's vertex count, vertex order, face order, and UV layout. The hair metadata must use the same topology and hair-map resolution. Replacing the reference OBJ with an unrelated mesh is not supported.

The hair metadata NPZ must contain `group_names`, `guide_group_id_map`, `uv_face_index_map`, and `uv_bary_map`. OBJ files must retain their `v`, `vt`, and `f` records. The training and inference loader reads geometry and UVs directly; MTL files are not required. Blender constructs the prediction materials from the UV texture and auxiliary maps.

## Pretrained models

The frozen Stable Diffusion VAE is loaded separately from the AnimalLift checkpoint. The default model is `stabilityai/sd-vae-ft-mse`. Inference restores the VAE identity and architecture from the checkpoint.

For a local VAE installation, put the Diffusers configuration and weights in a directory such as `assets/sd_vae/`, then configure:

```json
{
  "shared": {
    "vae_local_path": "assets/sd_vae",
    "vae_local_files_only": true
  }
}
```

Use the same VAE weights as the checkpoint. If its configuration specifies a VAE subfolder, preserve that subfolder inside the local directory.

DINOv2 is initialized through timm using `vit_small_patch14_dinov2.lvd142m`. Its pretrained weights must be downloaded or cached before an offline run. This initialization also occurs during inference, before the AnimalLift model state is restored. `vae_local_files_only` only controls VAE loading.

The optional texture-generation utility uses `Qwen/Qwen-Image-Edit-2511`, configured through `dataset_generation.model_id`. This model is not required for AnimalLift training or inference.

## Blender resources

The loader searches the Blender installation for the Essentials hair node library, `procedural_hair_node_assets.blend`. If it is installed elsewhere, set `blender.hair_nodes_path` to its location.

HDRI lighting is disabled by default. Set `blender.use_hdri` to `true` or pass `--use_hdri` to enable it. Normal and roughness maps are required when `blender.enable_texture_loading` is `true`, which is the default.

Optional density images can be loaded with `blender.density_dir`. This folder may contain `face.png`, `ear.png`, `neck.png`, `body.png`, `leg.png`, and `tail.png`. These images are loaded for inspection; they are not connected to the main hair modifiers automatically.

## Prediction files and training data

Prediction meshes, textures, and hair offsets are generated by `test.py`. Copy the complete result folder between machines, preserving `meshes/`, `textures/`, and `hair/` together. They do not belong in the static asset bundle.

Training uses paired images, UV textures, meshes, hair maps, and per-group `hair_info.json` annotations. See [Training data](DATASET.md) for the layout. The Blender prediction loader does not require `hair_info.json` or `length_maps/`.

The mean mesh cache is created during training. Inference reads `template_verts` from the checkpoint, so a separate `mean_template_verts.pt` is not required.

The Blender loader saves the constructed scene automatically to `<results>/blender/<sample>.blend` and packs loaded images by default. The saved geometry and packed textures can be opened on another machine without the prediction NPZ or image files. Blender must support the scene's hair node groups.
